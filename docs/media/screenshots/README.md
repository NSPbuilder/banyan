# Screenshot provenance

These are direct, unretouched browser captures of the independently branded Banyan 0.0.1 production build on 2026-10-28. They use an isolated PostgreSQL instance, the fictional Maple Demo Consulting Ltd. and synthetic transactions from `scripts/example-company.ts`. No production company, customer document, account or credential is pictured.

Viewport: 1920 × 1200 CSS pixels, device scale 1, headless Chromium. Full-page captures preserve content below the viewport when the document scrolls. Images are not generated mockups. Captures wait for actual document content, fonts and network idle; invoice and journal screenshots were visually checked to exclude streaming loading placeholders.

- `income.png`: invoice/payment/credit-note overview.
- `invoice.png`: INV-1001, CAD 5,040 settled total.
- `journal.png`: INV-00001, balanced receivables/revenue/tax posting.
- `financial-statements.png`: statement of financial position from the same ledger.
- `payroll.png`: synthetic Canadian federal/BC pay run and rate editions.

Screenshots document this preview and synthetic data; they are not evidence that every provider integration or statutory workflow is qualified. The publisher-supplied Banyan icon is included separately in `public/banyan-icon.png`.
