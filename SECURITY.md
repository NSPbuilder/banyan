# Security reporting

Never publish credentials, company books, original financial documents or personal data in an issue or pull request.

Use the published repository's private vulnerability-reporting facility if enabled. Otherwise contact the repository owner or NSP Labs AI Inc. through a verified private channel before disclosing exploit details. This package does not invent a security email address or response-time commitment.

Include the affected release, a minimal synthetic reproduction, impact and relevant configuration with secrets removed. For an exposed instance, restrict access and preserve evidence; rotate affected credentials through the normal administrative process.

No long-term support or security-update SLA is promised for 0.0.1. Operators are responsible for protecting database and file stores, updating dependencies, verifying backups and reviewing enabled external integrations.
