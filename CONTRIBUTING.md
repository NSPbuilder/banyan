# Contributing

Banyan is source available under [Elastic License 2.0](LICENSE). No separate CLA or copyright assignment is included in this release. Before proposing a contribution, confirm you have the right to submit the code and any assets under the project's applicable terms. Third-party material must retain its license and provenance.

Use the issue and pull-request facilities of the repository where this package is published. Report reproducible behavior, expected results and a minimal synthetic example. Never include customer books, personal records, credentials, original receipts or private environment files.

Preserve balanced posting rules, period controls, audit history, permission boundaries, database identity guards and backward-compatible archive/credential formats. Keep changes focused and run relevant isolated checks as described in [Development](docs/DEVELOPMENT.md). Do not report the full battery as passing while the known MV4 result remains red.
